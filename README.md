# zrob-je-wszystkie

Variants of a C test: linked lists and arrays.

University coursework from my Computer Science studies at UWM (2020–2024). I wrote the code by hand; the commit history is unchanged. This README was added in November 2026.

Years of work: 2021 (first commit on 8 June 2021, last commit on 11 June 2021).

## Contents

- `wariant-1/`, `wariant-2/`, `wariant-3/`, `wariant-jakis/`, `wariant z dzisiaj/`: solutions of the test variants.
- `3.c`, `4.c`, `wariant2_2.c`, `wariant3_2.c`: more solutions; `4.c` is a linked list without a head node.

With gcc 16 on Linux, 10 of the 15 `.c` files compile as they are, 1 uses `scanf_s` from Microsoft's C library, and 4 have other errors.

The repository also contains course materials: photos of the task sheets (`.jpg` and `.png` files in the variant folders).

## Running

```
gcc -o /tmp/wariant-2 wariant-2/main.c && /tmp/wariant-2
```

Result on 26 November 2026: 5 lines from `index: 0 wartosc: 1` to `index: 0 wartosc: 9`.
